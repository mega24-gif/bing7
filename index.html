Google Apps Script Setup Instructions

Langkah Integrasi Google Spreadsheet & Web App:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Beri nama header di Baris 1: Timestamp | Student Name | Class | Score | Total Questions | Percentage | Completed Activities
  3. Buka menu Extensions > Apps Script.
  4. Salin kode Code.gs di bawah ini lalu tempelkan ke editor Apps Script.
  5. Klik Deploy > New deployment. Pilih type Web app.
  6. Atur Execute as: Me, dan Who has access: Anyone. Klik Deploy.
  7. Salin Web App URL yang dihasilkan, lalu masukkan ke menu Configure URLs di aplikasi ini!
